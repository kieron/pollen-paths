# Sprites

Drop transparent PNGs here with these exact names, and they replace the procedural art automatically. You don't need to change any code. Missing files fall back to the placeholders.

| File | Shown as | Notes |
|---|---|---|
| `bee.png` | bee in flight | square, bee **facing right** |
| `wasp.png` | wasp | square, facing right |
| `hive.png` | straw skep hive | square, base of the hive at the bottom edge |
| `flower-daisy.png` | daisy | square, top-down-ish, centred |
| `flower-clover.png` | clover | ″ |
| `flower-thistle.png` | thistle | ″ |
| `flower-sunflower.png` | sunflower | ″ |
| `flower-lavender.png` | lavender | ″ |
| `flower-heather.png` | heather | ″ |
| `tree.png` | meadow-edge tree | square, trunk at bottom-centre |
| `rock.png` | rock | square |

512×512 is plenty. Keep the subject filling about 85% of the frame.

## Style prompt (gouache / Ghibli)

Start every Higgsfield prompt with the same style block so the set looks consistent:

> Hand-painted gouache illustration, Studio Ghibli–inspired, soft painterly brush texture, warm natural light, saturated but gentle greens and golds, subtle paper grain, clean silhouette, isolated single object on a plain transparent background, slight top-down three-quarter view, game sprite

Then add the subject, for example: *"…, a single white daisy with a golden centre and two small leaves"*.
